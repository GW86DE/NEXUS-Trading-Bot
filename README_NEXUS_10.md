# NEXUS 10.1.6

Update vom 15.09.2026: weniger PULSAR-Datenbanksperren, sichtbare und kontogebundene Behandlung der OKX-Ablehnung 54092, genaue Entscheidungs-IDs und Ausführungsergebnisse sowie dynamische X-Recherche zu PULSAR-Kandidaten.

Die bestehende PEP-Abrechnung und alle Risikosperren werden erhalten. X ergänzt die Recherche innerhalb des bestehenden 15-EUR-Monatsbudgets; X trifft keine alleinige Handels- oder Krisenentscheidung.
